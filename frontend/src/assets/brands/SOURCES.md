# Bundled service icons

Luma includes 11 recognizable service marks for identifying locally stored tokens.
These SVG path coordinates are copied unchanged from the [Simple Icons source
repository](https://github.com/simple-icons/simple-icons). They are rendered in
monochrome at their original 24 × 24 aspect ratio, using muted interface colors.
No service name or account is sent to an icon server. Unknown issuers use initials.

The exact upstream URL, version, original title and brand source for each path are
retained in `icons.json`. This is a deliberately selected local subset, not a claim
to include the newest Simple Icons release or every current brand revision.
